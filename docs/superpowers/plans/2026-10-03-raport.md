# Slice 1 Raport + Tingkat/Mapel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trainer mengisi dan admin memverifikasi raport semester per siswa, lalu mencetaknya dalam format exemplar — dengan `tingkat`/`mapel` sebagai field Data Siswa yang di-snapshot ke record raport.

**Architecture:** Entity `raport` baru mengikuti pola master-data `eksternal` (masterWrite/masterDelete + strict shape gate + cabangId diturunkan server, bukan dari klien); UI mengikuti idiom `InvoiceTemplate`/`InvoiceModal`/`StudentList` yang sudah ada; satu-satunya hitung-hitungan (total/rata-rata) tinggal di `src/lib/raport.js`.

**Tech Stack:** React 19 + Vite, Vitest (`npm test`), Playwright default project, PHP 8.2 (`D:\Games and Apps\xampp\php\php.exe`) + MySQL `afterschola_t3_test`, Tailwind existing.

**Spec:** `docs/superpowers/specs/2026-10-03-raport-design.md` (+ indeks `docs/FEATURE_SLICES_PLAN.md`)

## Global Constraints

- Copy UI dan pesan dialog Bahasa Indonesia; label tombol `Simpan`/`Batal`/`Hapus` (dipin agar test memilih via name).
- UI baru meniru idiom yang sudah ada verbatim (`InvoiceTemplate.jsx`, `InvoiceModal.jsx`, `StudentList.jsx`) — tidak ada warna/font/pola kartu-tabel-modal baru.
- Records hanya via factory (`newRaport()`, `newSiswa()` yang diperluas) — tidak ada object literal rakitan tangan ke store.
- Semua akses data via `src/lib/store.js` (`readCached`/`writeRemote`/`deleteRemote`); server adalah kontrak otoritatif RBAC.
- Tidak ada `console.log`/debug di `src/` (cek via grep sebelum DONE).
- Shell adalah cmd.exe: tidak ada heredoc; commit message multi-baris via flag `-m` berulang.
- PHP dijalankan via path eksplisit `D:\Games and Apps\xampp\php\php.exe`; tidak mengandalkan PATH.
- Langkah destruktif (db:reset, restore) selalu terakhir; data uji E2E disposable di browser, tidak seed DB bersama.
- Bahasa verifikasi: `Verified: <command> -> <result>`; yang tidak jalan tulis `Unverified:` + alasan.

## Review Focus

1. Raport ganda (siswa, semester, tahunAjaran) yang sama dari dua sesi → simpanan kedua harus update record yang sama, tidak pernah duplikat → diuji di Task 2 (unique DB) + Task 6 (E2E simpan-ulang → 1 record).
2. Trainer menulis raport murid sekolah yang tidak ditugaskan padanya → 403, tidak ada baris baru → diuji di Task 3 (authorize legs).
3. Tingkat/mapel siswa diubah setelah raport terbit → cetakan raport lama tidak berubah (snapshot) → diuji di Task 1 (unit snapshot-immutability).
4. Nilai di luar 0–100 atau grade kosong → 422 pesan Indonesia, input form tidak hilang → diuji di Task 2 (validator legs) + Task 6 (E2E pesan).
5. Cetak saat logo/settings kosong → template tetap render tanpa crash → diuji di Task 7 (E2E/template leg).
